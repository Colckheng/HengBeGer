# 韧性和弱点击破

> 来源：星穹铁道列车智库（灰机wiki），编辑者 Yuee，内容遵循 CC BY-SA 4.0 协议。

敌方弱点和韧性：弱点和韧性是敌人专有的特性，在敌方角色的上方会有指示器显示敌方的弱点和韧性条（白色），Boss则会将这部分信息显示在屏幕正上方。

## 基本信息

### 弱点效果

- 敌方的弱点属性的抗性为0%，非弱点属性则拥有至少20%的属性抗性
- 我方使用敌方弱点属性进行攻击时，会产生韧性削减，韧性削减时会产生击破效果

### 韧性效果

- 减伤效果：韧性效果存在时，敌方会有额外的10%伤害减免效果
- 韧性值：不同敌人的韧性量不同，以角色普攻的削韧量作为1，小怪一般是1~3的韧性，精英怪和Boss大部分为10或12，具体可以参考智库中敌人页，会标注各敌人的韧性量

### 韧性削减

我方使用敌方弱点属性进行攻击时，会产生韧性削减，韧性削减的效果量主要取决于攻击方式，与攻击造成的伤害、是否暴击等均无关系。模拟宇宙的祝福和部分角色会有额外的削韧性能，例如驭空/同谐的天赋可以提升驭空普攻的削韧效果。

下表是以角色普攻的削韧量作为1，显示一般削韧效果量的规律：

| 攻击类型 | 战技 | 终结技 |
|---|---|---|
| 单攻 | 2 | 3 |
| 扩散 | 目标 2 / 扩散 1 | 目标 2 / 扩散 2 |
| 群攻 | 全体 1 | 全体 2 |
| 弹射 | 目标 1 / 额外每击 0.5 | - |

## 击破效果

角色削减敌方全部韧性时，会产生击破，击破时会产生以下效果：

- 造成击破伤害：根据击破时使用的属性，产生一次对应属性的击破伤害，受到击破特攻的加成
- 附加属性负面状态：根据击破时使用的属性，以150%的基础概率使敌方进入该属性对应的负面效果，受到击破特攻的加成
- 行动延后25%
- 中断Boss的行动：Boss是连续两次行动，在第一次行动时插入终结技，通过终结技击破Boss，可以阻止Boss的第二次行动
- 中断敌方的技能准备：如兴风者的蓄力状态
- 移除特定的增益效果：如外宇宙之冰的【冰点】状态
- 进入击破状态，持续1回合。击破状态下，移除韧性提供的10%减伤，并且敌人无法行动

## 击破伤害

击破伤害的伤害计算公式如下：

$$击破伤害=击破基础伤害\times韧性值系数\times击破属性系数\times(1+击破特攻)\times其他修正$$

### 击破基础伤害

击破基础伤害只取决于角色等级，是预先配置好的固定数值。

| 角色等级 | 基础伤害 |
|---|---|
| 20 | 69.88517 |
| 30 | 115.5996 |
| 40 | 181.8329 |
| 50 | 387.4521 |
| 60 | 820.1534 |
| 70 | 1329.82 |
| 80 | 1883.777 |

### 韧性值系数

$$韧性值系数=\frac{韧性值+2}{4}$$

韧性值以角色普攻的削韧量作为1，衡量出的敌方总韧性量。

### 击破属性系数

根据击破属性，会有不同的击破伤害系数：

| 属性 | 系数 |
|---|---|
| 物理 | 4 |
| 火 | 4 |
| 冰 | 2 |
| 雷 | 2 |
| 风 | 3 |
| 量子 | 1 |
| 虚数 | 1 |

### 其他修正

其他修正包括抗性修正、易伤修正和减伤修正，关于这部分说明，请参考《伤害计算公式》。

## 击破负面效果

击破负面效果附带的持续伤害，只受到击破特攻和敌方的负面状态影响，不会受到《伤害计算公式》中提到的一些我方角色属性的加成：

- 伤害提高类的加成就是无效的，所以主打击破的角色，位面球不需要选用其对应属性的属性伤害加成球
- 光锥「延长记号」中提到的的伤害加成效果也是无效的，该光锥技能描述后半段的伤害加成只对角色技能造成的持续伤害有效（如桑博/虚无天赋施加的风化效果）

### 物理属性：裂伤

物理属性击破，会附加裂伤负面状态，持续2回合。该效果会在敌人行动开始前，对敌方造成物理属性持续伤害。与其他击破后的状态伤害相比，物理属性的击破伤害是基于敌人的最大生命值。

$$击破裂伤伤害=敌方最大生命值\times敌人类型系数\times(1+击破特攻)\times其他修正$$

普通敌人的类型系数为16%，精英和首领敌人的类型系数为7%。

### 火属性：灼烧

火属性击破，会附加灼烧负面状态，持续2回合。该效果会在敌人行动开始前，对敌方造成火属性持续伤害。

$$击破灼烧伤害=击破基础伤害\times2\times(1+击破特攻)\times其他修正$$

### 冰属性：冻结

冰属性击破，会附加冻结负面状态，持续1回合。该效果会在敌人行动开始前，对敌方造成冰属性附加伤害，并使敌人无法行动。冻结效果解除后，敌人不会解除击破状态，但下一次行动提前50%。

$$击破冻结伤害=击破基础伤害\times2\times(1+击破特攻)\times其他修正$$

### 雷属性：触电

雷属性击破，会附加触电负面状态，持续2回合。该效果会在敌人行动开始前，对敌方造成雷属性持续伤害。

$$击破触电伤害=击破基础伤害\times4\times(1+击破特攻)\times其他修正$$

### 风属性：风化

风属性击破，会附加风化负面状态，持续2回合。该效果会在敌人行动开始前，对敌方造成风属性持续伤害。

$$击破风化伤害=击破基础伤害\times2\times风化层数\times(1+击破特攻)\times其他修正$$

击破普通敌人时，会造成1层风化；击破精英和首领时，会造成3层风化。

### 量子属性：纠缠

量子属性击破，会使敌方额外行动延后 $20\%\times(1+击破特攻)$，并附加1层纠缠负面状态，持续1回合。该效果会在敌人行动开始前，对敌人造成量子属性附加伤害。与其他击破后的状态伤害相比，量子属性的附加伤害计算式中有韧性值系数，在对付高韧性的精英怪时会有比较高的伤害。

$$击破纠缠伤害=击破基础伤害\times韧性值系数\times1.2\times纠缠层数\times(1+击破特攻)\times其他修正$$

纠缠状态下敌人每次受到攻击，会使状态叠加1层，最多5层。

### 虚数属性：禁锢

虚数属性击破，没有额外的状态伤害，只会使敌方额外行动延后 $30\%\times(1+击破特攻)$，并减速10%，持续1回合。
