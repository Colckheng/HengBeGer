# 小小巨人

> English name: Little Giant

**ID**：100902 · **成员数**：5

---

敌人受到的伤害提高，造成的伤害降低。【小小巨人】可随羁绊层数不断提升【身高】，以强化技能效果！

| 层数  | 效果                                                       |
| ----- | ---------------------------------------------------------- |
| 层数2 | 获得1点【身高】。敌人受到的伤害提高12%，造成的伤害降低6%。 |
| 层数3 | 获得2点。敌人受到的伤害提高24%，造成的伤害降低12%。        |
| 层数4 | 获得3点。敌人受到的伤害提高36%，造成的伤害降低18%。        |
| 层数5 | 获得4点。敌人受到的伤害提高48%，造成的伤害降低24%。        |
| 层数6 | 获得6点。敌人受到的伤害提高60%，造成的伤害降低30%。        |

**备注**

- 【身高】：每点【身高】都会强化【小小巨人】角色的技能。
