# 云上五骁

> English name: High-Cloud Quintet

**ID**：100702 · **成员数**：5

---

【云上五骁】队员的伤害增幅提高，并在行动条上召唤【五骁连携】，行动时攻击敌方全体，并在攻击后使我方小队伤害增幅提高，可叠加。【云上五骁】队员行动后，使【五骁连携】行动提前。

| 层数  | 效果                                                                                                          |
| ----- | ------------------------------------------------------------------------------------------------------------- |
| 层数2 | 【五骁连携】造成等同于300%基础伤害的【云上五骁】队员对应属性伤害，并使我方小队获得10%伤害增幅，该效果可叠加。 |
| 层数3 | 速度提高至250，倍率提高至600%，20%伤害增幅。                                                                  |
| 层数4 | 速度提高至300，倍率提高至900%，40%伤害增幅。                                                                  |
| 层数5 | 速度提高至400，倍率提高至1800%，60%伤害增幅。                                                                 |

**羁绊成员**：[景元](../role/120402_景元.md)、[白露](../role/121102_白露.md)、[镜流](../role/121202_镜流.md)、[刃](../role/120502_刃.md)、[丹恒•饮月](../role/121302_丹恒•饮月.md)
