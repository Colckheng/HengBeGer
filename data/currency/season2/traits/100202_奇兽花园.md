# 奇兽花园

> English name: Beast Garden

**ID**：100202 · **成员数**：7

---

每节点获得【奇美能量】，用于招聘奇美拉入住【奇兽花园】，角色专属奇美拉还可以二合一升星！【奇兽花园】角色获得前台强度后台强度前/后台强度。

| 层数   | 效果                                                                    |
| ------ | ----------------------------------------------------------------------- |
| 层数3  | 每4点【奇美能量】可招聘奇美拉。                                         |
| 层数5  | 每3点【奇美能量】可招聘更多种奇美拉，并可刷新1次。                      |
| 层数7  | 每2点【奇美能量】可招聘奇美拉。每个奇美拉星级额外提高200%倍率，40速度。 |
| 层数10 | 奇美拉全体集结！                                                        |

**备注**

- 【奇美拉小队】：战斗中，奇美拉们组成小队，以0速度行动，攻击敌方全体造成0%基础伤害的物理属性伤害。每1个奇美拉总星级，都使【奇美拉小队】的倍率提高0%，速度提高0。
- 首次激活3/5/7/10羁绊时，可免费招聘一次！进入新节点时，若有足够【奇美能量】，则消耗能量以招聘奇美拉。

**羁绊成员**：[那刻夏](../role/140502_那刻夏.md)、[长夜月](../role/141302_长夜月.md)、[万敌](../role/140402_万敌.md)、[海瑟音](../role/141002_海瑟音.md)、[赛飞儿](../role/140602_赛飞儿.md)、[风堇](../role/140902_风堇.md)、[阿格莱雅](../role/140202_阿格莱雅.md)
