# 欢愉

> English name: Elation

**ID**：200702 · **成员数**：9

---

【欢愉】队员的幸运一击率和速度增幅提高。备战阶段召唤【阿哈】为小队提供增益，【阿哈】拥有初始属性并穿戴3件随机简易装备，可从商店购买【阿哈装备】拖拽给【阿哈】，依次合成对应进阶装备。商店中也有概率刷出【阿哈小道具】！【阿哈】会参演阿哈时刻，并有概率掉落晶矿奖励！

| 层数  | 效果                                                  |
| ----- | ----------------------------------------------------- |
| 层数3 | 8%幸运一击率，8%速度增幅。                            |
| 层数4 | 二星阿哈，2个装备栏，出现【阿哈小道具】。             |
| 层数6 | 三星阿哈，3个装备栏，更妙妙的【阿哈小道具】。         |
| 层数8 | 四星阿哈，竟然能穿4件装备？！有较高概率掉落棱彩晶矿。 |
