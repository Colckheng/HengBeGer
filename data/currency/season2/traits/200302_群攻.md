# 群攻

> English name: AoE ATK

**ID**：200302 · **成员数**：7

---

【群攻】队员的伤害增幅提高。战斗中，为生命上限最高的敌人创造能够转移伤害的【灵魂】。

| 层数  | 效果                                                                                                                                                                                                                   |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 层数2 | 【灵魂】的伤害转移效率为15%。                                                                                                                                                                                          |
| 层数4 | 20%伤害转移效率。                                                                                                                                                                                                      |
| 层数6 | 伤害转移效率提高至25%。被攻击后记录受到非真实伤害的35%，每击中1个目标，记录比例提高100%。行动序列上出现300速度的【灵魂】，【灵魂】的本体被消灭或【灵魂】行动时，造成等同记录值、由敌方全体分摊的真实伤害，行动后清零。 |
| 层数8 | 30%伤害转移效率，记录比例提高至50%。                                                                                                                                                                                   |

**备注**

- 【灵魂】：受到攻击后，对本体造成真实伤害，数值等同于所受非真实伤害的一定比例。【灵魂】免疫控制类负面状态。【灵魂】的本体被消灭时，重新创造当前生命上限最高的敌方目标的【灵魂】。
