# 星核猎手

> English name: Stellaron Hunters

**ID**：100802 · **成员数**：5

---

艾利欧为【星核猎手】揭示3件进阶装备为本局剧本装备，并随羁绊等级解锁并发放。不同类型的剧本装备，将为装备者/我方小队将提供伤害增幅，【星核猎手】穿戴时双倍生效。

| 层数  | 效果                                                             |
| ----- | ---------------------------------------------------------------- |
| 层数2 | 解锁并发放1件装备。剧本装备提供给装备者/我方小队20%/8%伤害增幅。 |
| 层数3 | 解锁并发放2件装备。                                              |
| 层数5 | 解锁并发放3件装备。剧本装备提供30%/12%伤害增幅。                 |
| 层数7 | 羁绊发放的装备全部变为特权装备，剧本装备提供60%/24%伤害增幅。    |

**备注**

- 【剧本装备】：与所揭示装备同名的所有装备都是剧本装备，并提供对应加成。去合成更多剧本装备吧！
