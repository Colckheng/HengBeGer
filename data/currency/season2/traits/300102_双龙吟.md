# 双龙吟

> English name: Twin Dragons' Call

**ID**：300102 · **成员数**：2

---

【丹恒•饮月】在后台区域召唤星级相同的【丹恒•腾荒】，并复制其穿戴的装备以获得相应效果，可穿戴数量随星级提高。【丹恒•饮月】/【丹恒•腾荒】行动后为【双龙吟】充能，充能满时合击敌人并提供护盾。

| 层数  | 效果                                           |
| ----- | ---------------------------------------------- |
| 层数1 | 进入战斗时，在后台区域召唤【丹恒•腾荒】。     |
| 层数2 | 1/2/3星时，可为【丹恒•腾荒】穿戴1/2/3件装备。 |

**备注**

- 【双龙吟】：【丹恒•饮月】/【丹恒•腾荒】/【龙灵】行动后，为【双龙吟】充能2/1/1点，上限12点。充满时消耗12点，对敌方全体造成1000%基础伤害的虚数属性伤害和1000%基础伤害的物理属性伤害，并为我方前台提供等同于其生命上限30%的护盾。

**羁绊成员**：[丹恒•饮月](../role/121302_丹恒•饮月.md)、[丹恒•腾荒](../role/141402_丹恒•腾荒.md)
