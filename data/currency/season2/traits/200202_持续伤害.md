# 持续伤害

> English name: DoT

**ID**：200202 · **成员数**：7

---

【持续伤害】队员的持续伤害增幅提高，召唤【深红荆棘】攻击敌人，施加并结算持续伤害。我方行动中使敌人陷入持续伤害时，【深红荆棘】的结算倍率提高且行动提前。

| 层数  | 效果                                                                           |
| ----- | ------------------------------------------------------------------------------ |
| 层数3 | 15%持续伤害增幅。                                                              |
| 层数5 | 【深红荆棘】的行动速度提高至300。                                              |
| 层数7 | 【深红荆棘】行动时，额外使敌人陷入的持续伤害产生1次伤害。                      |
| 层数9 | 【深红荆棘】的行动速度提高至450，基础伤害倍率提高至1200%，结算倍率提高至300%。 |

**备注**

- 【深红荆棘】：以2速度行动，行动时攻击敌方全体，造成100%基础伤害的风属性伤害，并有0%基础概率施加随机持续伤害，使目标陷入的持续伤害立即产生等同于原伤害15000%的伤害。我方行动中使敌人陷入持续伤害时，【深红荆棘】的结算倍率提高0%，且行动提前0%。
