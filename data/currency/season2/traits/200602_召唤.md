# 召唤

> English name: Summon

**ID**：200602 · **成员数**：6

---

【召唤】队员的前台强度后台强度前/后台强度提高，并获得20%生命增幅。激活【召唤】专属角色赋能。根据【召唤力】增强其效果。

| 层数  | 效果                                            |
| ----- | ----------------------------------------------- |
| 层数2 | 25%前台强度后台强度前/后台强度。1点【召唤力】。 |
| 层数4 | 50%前台强度后台强度前/后台强度。2点【召唤力】。 |
| 层数6 | 1%前台强度后台强度前/后台强度。3点【召唤力】。  |
| 层数8 | 2%前台强度后台强度前/后台强度。4点【召唤力】。  |

**备注**

- 【召唤力】：每点【召唤力】都会强化【召唤】专属角色赋能。
