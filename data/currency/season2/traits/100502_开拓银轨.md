# 开拓银轨

> English name: Trailblaze Silver Rail

**ID**：100502 · **成员数**：7

---

每个战斗阶段后积攒【开拓力】，可在【开拓商店】内购买角色和道具。随着羁绊层级提升，【开拓商店】还会解锁更稀有的商品！

| 层数   | 效果                                             |
| ------ | ------------------------------------------------ |
| 层数2  | 20【开拓力】。星穹列车，启动！                   |
| 层数4  | 45【开拓力】。商品变得更好。                     |
| 层数6  | 75【开拓力】。商品变得更好，并出现羁绊专属改件。 |
| 层数8  | 125【开拓力】。                                  |
| 层数10 | 225【开拓力】！列车进化！                        |

**备注**

- 【开拓商店】：消费【开拓力】，在商店购买【开拓银轨】角色、属性加成、消耗品、羁绊专属改件，以及强化你的列车！
