# 连击

> English name: Combo

**ID**：200402 · **成员数**：7

---

【连击】队员的幸运一击率提高。在场上生成【连击地格】，可提供伤害增幅普攻/战技伤害增幅和【连击率】。

| 层数  | 效果                                                                                                                                       |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 层数2 | 8%【连击率】。                                                                                                                             |
| 层数4 | 16%，后台额外生成【连击地格】。【连击地格】上的角色在消耗获得的额外回合内的攻击造成原伤害30%的真实伤害，首次行动后必定消耗并获得额外回合。 |
| 层数6 | 24%，连击时造成的真实伤害提高至60%。                                                                                                       |
| 层数8 | 32%，连击时造成的真实伤害提高至90%。                                                                                                       |

**备注**

- 【连击地格】：进入战斗时，此地格上的角色获得0%伤害增幅普攻/战技伤害增幅，【连击】角色获得双倍；此地格上的角色施放普攻或战技时获得【连击率】。
- 【连击率】：施放普攻或战技后，每1%【连击率】有1%概率获得额外回合，并消耗当前【连击率】至基础值。默认基础【连击率】为0。
