# 梦境交织

> English name: Intertwined Dreamscapes

**ID**：101002 · **成员数**：5

---

选择两位【梦境交织】角色，总计行动12次后触发【共舞】，共同进行攻击。

| 层数  | 效果                                                                             |
| ----- | -------------------------------------------------------------------------------- |
| 层数2 | 总计行动12次后将触发【共舞】。                                                   |
| 层数3 | 战斗中，舞伴互相提供40%前台强度后台强度和20%速度增幅，前台强度后台强度取较高项。 |
| 层数4 | 【共舞】效果提高。80%前台强度后台强度和40%速度增幅转化。                         |
| 层数5 | 【共舞】效果提高。120%前台强度后台强度和60%速度增幅转化。                        |

**备注**

- 【共舞】：双方共同攻击，并提供独特效果，初始已计入6次行动。
- 【黑天鹅】：施放追加攻击，使敌方全体受到的伤害提高20%，持续2回合。
- 【长夜月】：获得16点【忆质】并施放忆灵技，并提高我方小队10%生命增幅和10%治疗强度，持续2回合。
- 【花火】：施放战技，并使目标造成的伤害提高40%，持续2回合。
- 【大丽花】：使舞伴【共舞】效果提高100%，并施放追加攻击。
- 【黄泉】：施放终结技，造成等同于原伤害120%的伤害。
- 【星徽】：获得额外回合并自动行动，获得20%前台强度后台强度前/后台强度和10点速度。
- 仅激活角色赋能的【梦境交织】角色可生效【共舞】效果。

**羁绊成员**：[黑天鹅](../role/130702_黑天鹅.md)、[长夜月](../role/141302_长夜月.md)、[花火](../role/130602_花火.md)、[大丽花](../role/132102_大丽花.md)、[黄泉](../role/130802_黄泉.md)
