# 反击

> English name: Counter

**ID**：200802 · **成员数**：5

---

装备最多的前台【反击】角色成为【反击王】：更易受到攻击并【反伤】。进入战斗时，每个后台【反击】角色为其提供30%伤害增幅，10%生命增幅。【反击】队员可以【挑衅】敌方目标。

| 层数  | 效果                                                                |
| ----- | ------------------------------------------------------------------- |
| 层数2 | 反伤对攻击者造成400%基础反击伤害。【挑衅】使敌人受到的伤害提高20%。 |
| 层数4 | 800%倍率反伤。【挑衅】使敌人受到的伤害提高40%。                     |
| 层数6 | 1200%倍率反伤。【挑衅】使敌人受到的伤害提高80%。                    |

**备注**

- 【挑衅】：【反击】队员/【反击王】行动后积攒1点/2点充能。充满15点时，【反击王】的攻击消耗充能，并使该次攻击中生命上限最高的敌方目标立即行动，且敌方全体受到的伤害提高，持续3回合。
- 【反伤】：基于基础反击伤害造成相应属性附加伤害，基础反击伤害随节点进度提高。反伤无法消灭敌方目标。
