# 星间旅人

> English name: Galactic Voyager

**ID**：100402 · **成员数**：7

---

| 层数  | 效果       |
| ----- | ---------- |
| 层数1 | 100%加成。 |
| 层数2 | 120%加成。 |
| 层数3 | 140%加成。 |
| 层数4 | 170%加成。 |
| 层数5 | 200%加成。 |
| 层数6 | 240%加成。 |
| 层数7 | 290%加成。 |
| 层数8 | 350%加成。 |
