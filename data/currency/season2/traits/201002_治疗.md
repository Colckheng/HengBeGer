# 治疗

> English name: Heal

**ID**：201002 · **成员数**：6

---

我方小队伤害减免12%。【治疗】队员的治疗强度提高。

| 层数  | 效果                                   |
| ----- | -------------------------------------- |
| 层数2 | 治疗强度提高20%。                      |
| 层数4 | 治疗强度提高40%。                      |
| 层数6 | 60%治疗强度，我方小队获得60%伤害增幅。 |
