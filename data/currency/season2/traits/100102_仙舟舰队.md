# 仙舟舰队

> English name: Xianzhou Fleet

**ID**：100102 · **成员数**：7

---

战斗开始前，【仙舟舰队】队员的部分简易装备临时变为进阶装备！【仙舟舰队】队员伤害增幅提高。

| 层数  | 效果                                                                                                                    |
| ----- | ----------------------------------------------------------------------------------------------------------------------- |
| 层数2 | 变化1件简易装备为推荐装备。每件装备提供3%伤害增幅。                                                                     |
| 层数4 | 变化2件。每件装备提供5%伤害增幅。进入战斗时，召唤【星槎】攻击敌人，我方队员携带更多装备时，每件使【星槎】速度提高10点。 |
| 层数6 | 变化所有简易装备。每件装备提供7%伤害增幅。                                                                              |
| 层数9 | 所有简易装备都会变为特权装备！每件装备提供10%伤害增幅。                                                                 |

**备注**

- 进阶装备/特权装备算作2/4件简易装备。
- 【星槎】：以150速度行动，对敌方全体目标造成400%基础伤害的火属性伤害，额外造成【仙舟舰队】队员累计总伤害50%的真实伤害，由敌方全体分摊，攻击后清空累计值。
