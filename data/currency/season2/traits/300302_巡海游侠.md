# 巡海游侠

> English name: Galaxy Ranger

**ID**：300302 · **成员数**：1

---

不死途在场时，选择1名前台角色，将其任命为【巡海游侠】，【巡海游侠】们的星级会提高他们的伤害增幅和速度增幅。

| 层数  | 效果                                                                    |
| ----- | ----------------------------------------------------------------------- |
| 层数1 | 任命1名前台角色为【巡海游侠】。                                         |
| 层数2 | 每名【巡海游侠】提供30%伤害增幅，30%速度增幅，2/3/4星角色提供3/6/12倍。 |

**羁绊成员**：[不死途](../role/150402_不死途.md)
