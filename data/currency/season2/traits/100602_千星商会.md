# 千星商会

> English name: Astropolis Merchant Guild

**ID**：100602 · **成员数**：6

---

每上场1位3星【千星商会】角色，将激活1级羁绊效果。每位【千星商会】角色为羁绊内队员提供2%幸运一击率和幸运一击伤害，加成随星级提高。【千星商会】角色的出现概率不会随着商店等级提升而下降。

| 层数  | 效果 |
| ----- | ---- |
| 层数2 | -    |

**备注**

- 1/2/3/4星的【千星商会】队员，提供1/2/4/8倍幸运一击率和幸运一击伤害。

**羁绊成员**：[托帕&账账](../role/111202_托帕&账账.md)、[真珠](../role/150302_真珠.md)、[知更鸟•晴歌](../role/151202_知更鸟•晴歌.md)、[爻光](../role/150202_爻光.md)、[砂金•戏浪](../role/151302_砂金•戏浪.md)、[翡翠](../role/131402_翡翠.md)
