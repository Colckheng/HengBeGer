# 追击

> English name: Follow-Up ATK

**ID**：200102 · **成员数**：7

---

敌人受到伤害后，可累积【KO值】以触发斩杀。【追击】队员前台强度后台强度前/后台强度提高，攻击后额外累积【KO值】。

| 层数   | 效果                                                                                                        |
| ------ | ----------------------------------------------------------------------------------------------------------- |
| 层数3  | 敌方目标受到伤害的20%累积为【KO值】。                                                                       |
| 层数5  | 累积比例提高至30%。                                                                                         |
| 层数7  | 累积比例提高至50%。触发【KO】时，对相邻目标造成等同于800%基础伤害的量子属性附加伤害。                       |
| 层数10 | 累积比例提高至100%，附加伤害倍率大幅提高。触发【KO】时，额外对敌方全体目标造成3000%基础伤害的量子属性伤害。 |

**备注**

- 【KO值】：敌人被攻击后，会将受到的非真实伤害按一定比例累积为【KO值】，若累积值大于等于当前生命值，则立即被斩杀，受到等同于当前生命值的固定伤害。
