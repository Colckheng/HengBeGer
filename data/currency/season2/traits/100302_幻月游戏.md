# 幻月游戏

> English name: Phantasmoon Games

**ID**：100302 · **成员数**：7

---

每局游戏开始时，【幻月游戏】将为你带来不同的游戏规则。

| 层数   | 效果     |
| ------ | -------- |
| 层数3  | 幻月游戏 |
| 层数5  | 幻月游戏 |
| 层数7  | 幻月游戏 |
| 层数10 | 幻月游戏 |

**子羁绊**

- **幻月游戏•愿力**：每局游戏开始时，【幻月游戏】将展示不同的游戏规则。本局游戏规则：【愿力】。每个战斗阶段后，积蓄【愿力】，完胜后获得2倍。积蓄足够的【愿力】可以获得晶矿奖励。【幻月游戏】队员的前台强度后台强度前/后台强度提高。
- **幻月游戏•经验**：每局游戏开始时，【幻月游戏】将展示不同的游戏规则。本局游戏规则：【经验】。进入新节点时，获得经验。【幻月游戏】队员的前台强度后台强度前/后台强度提高，每个商店等级额外提高前台强度后台强度。
- **幻月游戏•唱名**：每局游戏开始时，【幻月游戏】将展示不同的游戏规则。本局游戏规则：【唱名】。你的角色进行【唱名】并获得属性加成。
