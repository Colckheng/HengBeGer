# 击破

> English name: Break

**ID**：200502 · **成员数**：6

---

【击破】队员的击破伤害增幅和速度增幅提高。敌人获得【多重韧性条】：初始韧性被削减至0后可继续削减，被削减至0时再次受到弱点击破伤害。敌人被击破时还会受到额外伤害。

| 层数  | 效果                                                                       |
| ----- | -------------------------------------------------------------------------- |
| 层数2 | 【多重韧性条】为初始值的60%。每次击破后比例上升24%，最高不超过初始值的480% |
| 层数4 | 52%【多重韧性条】。击破后比例上升20%，不超过初始值的400%                   |
| 层数6 | 44%【多重韧性条】。击破后比例上升16%，不超过初始值的320%                   |
| 层数8 | 36%【多重韧性条】。击破后比例上升12%，不超过初始值的240%                   |

**备注**

- 【多重韧性条】：敌方目标额外获得等同于自身韧性上限一定比例的【多重韧性条】，被削减至0时会再次受到弱点击破伤害。单次攻击可击破多条。【多重韧性条】的初始比例较低，每次击破后比例上升，但不超过原始韧性上限。
