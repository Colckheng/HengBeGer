# 能量

> English name: Energy

**ID**：2004 · **成员数**：8

---

【能量】队员的终结技伤害增幅提高。在场上生成【能量地块】，可提供伤害增幅和能量恢复。

| 层数   | 效果                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| 层数3  | 20%终结技伤害增幅。                                                                                                  |
| 层数5  | 【能量】角色施放终结技时，记录消耗的能量值。累计500点后，消耗500点，并对敌方全体目标造成800%基础伤害的物理属性伤害。 |
| 层数7  | 累计值造成的伤害倍率提高至1800%。                                                                                    |
| 层数10 | 场上所有地格变为【能量地块】，累计值造成的伤害倍率提高至12000%。                                                     |

**备注**

- 【能量地块】：进入战斗时，此地格上的角色获得30%伤害增幅，【能量】角色获得双倍。任一【能量】角色施放终结技后，此地格上的角色固定恢复3%能量。
