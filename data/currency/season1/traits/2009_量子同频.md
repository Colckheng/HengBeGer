# 量子同频

> English name: Quantum Resonance

**ID**：2009 · **成员数**：4

---

敌人受到的伤害提高。【量子同频】角色获得可强化技能效果的【同频】。

| 层数  | 效果                                          |
| ----- | --------------------------------------------- |
| 层数2 | 获得1层【同频】，敌方目标受到的伤害提高15%。  |
| 层数3 | 获得2层【同频】，敌方目标受到的伤害提高30%。  |
| 层数4 | 获得3层【同频】，敌方目标受到的伤害提高60%。  |
| 层数5 | 获得4层【同频】，敌方目标受到的伤害提高100%。 |

**备注**

- 【同频】：每层都会强化【量子同频】角色的技能。

**羁绊成员**：[花火](../role/1306_花火.md)、[缇宝](../role/1403_缇宝.md)、[希儿](../role/1102_希儿.md)、[符玄](../role/1208_符玄.md)

**专家顾问**：[银狼](../role/1006_银狼.md)
