# 减益

> English name: Debuff

**ID**：2007 · **成员数**：6

---

【减益】队员的前台强度后台强度前/后台强度提高，行动时使敌方陷入负面效果时，为随机目标附加【离火】，使其造成的伤害降低，并且被攻击后受到额外伤害。

| 层数  | 效果                                                       |
| ----- | ---------------------------------------------------------- |
| 层数2 | 每层造成的伤害降低3%，10%真实伤害，【离火】上限3层。       |
| 层数4 | 每层造成的伤害降低4%，20%真实伤害。                        |
| 层数6 | 每层造成的伤害降低5%，30%真实伤害，【离火】上限提高到5层。 |
| 层数8 | 每层造成的伤害降低6%，50%真实伤害。                        |

**备注**

- 【离火】：目标造成的伤害降低，并且受到攻击后，根据层数额外受到基于原伤害的真实伤害。【离火】在目标被消灭时转移。
