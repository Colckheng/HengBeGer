# 战技点

> English name: Skill Points

**ID**：2011 · **成员数**：6

---

我方战技点上限提高，我方小队获得速度增幅，施放战技或普攻时获得伤害增幅。【战技点】队员消耗战技点时，每个战技点进行1次抽奖。

| 层数  | 效果                                                                                              |
| ----- | ------------------------------------------------------------------------------------------------- |
| 层数2 | 获得12%伤害增幅，战技点上限提高2，可抽到小奖。                                                    |
| 层数4 | 获得24%伤害增幅，战技点上限提高3，可抽到中奖和大奖。                                              |
| 层数6 | 获得48%伤害增幅，战技点上限提高4，抽奖时有概率额外获得1次特别奖，抽到更好奖励的概率提高。         |
| 层数8 | 获得80%伤害增幅，战技点上限提高5，抽奖时有更高概率额外获得1次特别奖，抽到更好奖励的概率大幅提高。 |

**备注**

- 【谢谢惠顾】伤害增幅提高2%，持续至自身回合结束。
- 【小奖】恢复1个战技点。
- 【中奖】伤害增幅提高6%，持续至自身回合结束。
- 【大奖】获得1个额外回合，并恢复4个战技点。
- 【特别奖】获得1个金币！！！
