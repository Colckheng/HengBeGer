# 追击

> English name: Follow-Up ATK

**ID**：2001 · **成员数**：7

---

【追击】队员的追加攻击伤害增幅提高，并在攻击后额外附伤。我方小队连续行动会提高【追击】队员的追加攻击伤害增幅，持续至任意敌人回合开始。

| 层数  | 效果                                                                                               |
| ----- | -------------------------------------------------------------------------------------------------- |
| 层数3 | 连续行动提供5%追加攻击伤害增幅，最多20%。                                                          |
| 层数5 | 连续行动提供10%追加攻击伤害增幅，最多40%。连续行动达到5次后：可发动【总攻击】，造成60%的真实伤害。 |
| 层数7 | 连续行动提供15%追加攻击伤害增幅，最多60%。【总攻击】造成120%的真实伤害。                           |
| 层数9 | 连续行动提供30%追加攻击伤害增幅，最多120%。【总攻击】造成240%的真实伤害。                          |

**备注**

- 【总攻击】：连续行动多次后，在敌方目标回合开始时触发总攻击，基于触发前羁绊内队员累计的追击伤害造成一定比例的真实伤害，随后清空累计值。
