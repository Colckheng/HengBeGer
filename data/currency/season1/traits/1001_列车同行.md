# 列车同行

> English name: Express Cohort

**ID**：1001 · **成员数**：7

---

召唤【星穹列车】撞击敌人并留下【光轨】，使我方小队的前台强度后台强度前/后台强度提高。

| 层数  | 效果                                                                                                            |
| ----- | --------------------------------------------------------------------------------------------------------------- |
| 层数2 | 战斗开始时撞击并提供1层【光轨】，使我方小队前台强度后台强度前/后台强度提高20%。                                 |
| 层数4 | 列车额外以300速度撞击，每层【光轨】提供的前台强度后台强度提高至40%，最多叠加2层。【列车同行】队员获得双倍收益。 |
| 层数6 | 每层【光轨】提供的前台强度后台强度提高至60%，可叠加上限提高至3层，每层额外使敌方全体目标防御力降低10%。         |
