# 盛会之星

> English name: The Planet of Festivities

**ID**：1010 · **成员数**：5

---

选择1名【盛会之星】角色作为【巨星】，使我方小队获得独特加成。

| 层数  | 效果                     |
| ----- | ------------------------ |
| 层数2 | 获得选定【巨星】的加成。 |
| 层数3 | 加成提高。               |
| 层数4 | 加成提高。               |
| 层数5 | 加成提高。               |
| 层数6 | 加成提高。               |

**备注**

- 【大丽花】击破伤害增幅提高，速度增幅提高。
- 【花火】进入战斗时获得战技点，伤害增幅普攻/战技伤害增幅提高。
- 【星期日】前台第一位角色前台强度提高，后台第一位角色后台强度提高。
- 【知更鸟】幸运一击率提高。
- 【黑天鹅】我方小队中每有1个5费角色，则伤害增幅提高，可叠加。
- 【星徽】我方小队每装备了1个星徽，则前台强度后台强度前/后台强度提高，可叠加。
- 【加拉赫】击破伤害增幅提高，治疗强度提高。

**子羁绊**

- **盛会之星—加拉赫先生！**：我方小队击破伤害增幅提高，治疗强度提高。
- **盛会之星—花火女士！**：我方小队伤害增幅普攻/战技伤害增幅提高，进入战斗时获得战技点。
- **盛会之星—星期日先生！**：前台/后台第一位角色的前台强度/后台强度提高。
- **盛会之星—知更鸟女士！**：我方小队幸运一击率提高。
- **盛会之星—黑天鹅女士！**：上场的每1个5费角色，都会使我方小队的伤害增幅提高。
- **盛徽之星—友情出演！**：我方小队每携带1个星徽，都会使我方小队前台强度后台强度前/后台强度提高。
- **盛会之星—大丽花女士！**：我方小队击破伤害增幅提高，速度增幅提高。
