# 巡海游侠

> English name: Galaxy Ranger

**ID**：1009 · **成员数**：4

---

【巡海游侠】们获得伤害增幅和速度增幅。若将【巡海游侠】放置于后台，则位于后台的【巡海游侠】的星级会使前台【巡海游侠】额外获得伤害增幅和速度增幅。

| 层数  | 效果                                     |
| ----- | ---------------------------------------- |
| 层数1 | 8%伤害增幅，8%速度增幅。                 |
| 层数2 | 16%伤害增幅，16%速度增幅。               |
| 层数3 | 28%伤害增幅，28%速度增幅。               |
| 层数4 | 【巡海游侠】队员进入战斗时行动提前100%。 |

**备注**

- 1/2/3/4星的后台【巡海游侠】，提供1/3/6/12倍伤害增幅和速度增幅。
