# 欢愉

> English name: Elation

**ID**：2012 · **成员数**：8

---

【欢愉】队员的幸运一击率提高。备战阶段召唤【阿哈】为小队提供增益，【阿哈】拥有初始属性并穿戴3件随机简易装备，可将物品栏中简易装备拖拽给阿哈，合成对应进阶装备。

| 层数  | 效果                                      |
| ----- | ----------------------------------------- |
| 层数3 | 8%幸运一击率。                            |
| 层数4 | 阿哈升至2星，解锁第2个装备栏。            |
| 层数5 | 阿哈升至3星，解锁第3个装备栏。            |
| 层数7 | 阿哈升至4星！阿哈的所有装备变成特权装备！ |

**备注**

- 【阿哈】在阿哈时刻期间始终视为攻击者（因此可触发相应进阶装备效果），并向小队分享自己的攻击类属性。
