# 燃血

> English name: Bloodflame

**ID**：2006 · **成员数**：7

---

【燃血】队员的生命增幅和伤害增幅提高。战斗开始时，激活会记录【燃血】队员消耗生命值并在行动时攻击敌方全体的【燃血角斗场】。【燃血】队员无法获得护盾，受到护盾时会回复2%生命上限+1000生命值。

| 层数  | 效果                                                         |
| ----- | ------------------------------------------------------------ |
| 层数2 | 可记录40000点。                                              |
| 层数4 | 可记录100000点，伤害倍率提高为1000%。                        |
| 层数6 | 可记录240000点，伤害倍率提高为2000%，行动后返还消耗量的30%。 |
| 层数8 | 可记录720000点，伤害倍率提高为4000%，行动后返还消耗量的50%。 |

**备注**

- 【燃血角斗场】：记录【燃血】队员已损失的生命值，每10000点额外为【燃血】队员提供5%伤害增幅。并以300速度行动，行动时消耗所有记录值对敌方全体造成总量500%/1000%/2000%/4000%+100%/200%/300%/400%基础伤害的物理属性伤害。
