# 狼狩

> English name: Wolf Hunt

**ID**：1008 · **成员数**：6

---

召唤【步离人】协同战斗，其在参与战斗后可以获得经验并升级。我方队员携带更多装备会使其额外获得经验。【狼狩】队员的前台强度后台强度前/后台强度提高，【步离人】每次升级后使该加成提高50%。

| 层数  | 效果                             |
| ----- | -------------------------------- |
| 层数3 | 15%前台强度后台强度前/后台强度。 |
| 层数5 | 2倍经验。                        |
| 层数6 | 3倍经验。                        |
| 层数8 | 6倍经验。                        |

**备注**

- 【步离人】：参与战斗后获得4点经验，我方队员每携带1件简易装备，就会在战斗后额外使其获得1点经验，获得足够的经验后【步离人】会升级，造成更多伤害并提供增益。进阶装备和特权装备算作2件简易装备。
