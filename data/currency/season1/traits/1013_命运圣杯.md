# 命运圣杯

> English name: Holy Grail of Destiny

**ID**：1013 · **成员数**：4

---

【命运圣杯】提供祈愿试炼，完成试炼以获得各种奖励。祈愿试炼的难度和奖励随羁绊等级提升。【命运圣杯】成员的前台强度后台强度前/后台强度提高。

| 层数  | 效果                                               |
| ----- | -------------------------------------------------- |
| 层数2 | 开启首个祈愿试炼。                                 |
| 层数3 | 第二个祈愿试炼，出现奖励更好、难度更高的诅咒试炼。 |
| 层数4 | 第三个祈愿试炼。                                   |
| 层数5 | 最终祈愿试炼。                                     |

**子羁绊**

- **命运圣杯**：【命运圣杯】提供祈愿试炼，完成试炼以获得各种奖励。祈愿试炼的难度和奖励随羁绊等级提升。【命运圣杯】成员的前台强度后台强度前/后台强度提高。
- **命运圣杯•投影**：【命运圣杯】羁绊的投影。圣杯的魔力尚未充盈，因此未开启祈愿试炼。在此阶段，【命运圣杯】羁绊会根据羁绊分级为全队提供临时增益。【命运圣杯】羁绊玩法将在联动相关内容上线后正式更新！
