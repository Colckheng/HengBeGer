# 仙舟

> English name: Xianzhou

**ID**：1007 · **成员数**：7

---

【仙舟】召唤【神君】。【仙舟】队员行动后为【神君】叠加段数并使其行动提前。【仙舟】队员的前台强度后台强度前/后台强度和速度增幅提高。

| 层数   | 效果                                                                   |
| ------ | ---------------------------------------------------------------------- |
| 层数3  | 20%前台强度后台强度前/后台强度，8%速度增幅。                           |
| 层数5  | 【神君】基础伤害段数增加至6。                                          |
| 层数7  | 【仙舟】队员行动后叠加的伤害段数提高至2，战斗开始时【神君】立即行动。  |
| 层数10 | 【神君】基础伤害段数增加至10，每段倍率提高至600%，并更频繁地发动攻击！ |

**备注**

- 【神君】：以150速度行动，行动时对敌方全体目标造成300%/600%/900%/1200%基础伤害的雷属性伤害，并对随机敌方目标造成多段伤害。【仙舟】队员行动后为神君增加攻击段数，并使神君行动提前10%/10%/10%/25%。
