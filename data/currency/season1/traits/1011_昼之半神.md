# 昼之半神

> English name: Day Demigod

**ID**：1011 · **成员数**：6

---

获得仅供【昼之半神】穿戴的白昼装备。【昼之半神】队员的前台强度后台强度前/后台强度和速度增幅提高。

| 层数  | 效果                                                                                     |
| ----- | ---------------------------------------------------------------------------------------- |
| 层数3 | 获得【白昼•光速螺旋桨】。                                                               |
| 层数4 | 获得【白昼•武器大师】。                                                                 |
| 层数6 | 获得【白昼•斩首行动】。                                                                 |
| 层数9 | 白昼装备的特殊效果获得增强。进入战斗时，为你的【昼之半神】角色们穿戴满强化后的白昼装备！ |
