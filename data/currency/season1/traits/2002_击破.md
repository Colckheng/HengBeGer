# 击破

> English name: Break

**ID**：2002 · **成员数**：7

---

【击破】队员的前台强度后台强度前/后台强度提高，并在攻击处于弱点击破状态的敌方目标后造成超击破伤害。敌人的初始韧性和韧性恢复量降低。

| 层数  | 效果                                                                                                 |
| ----- | ---------------------------------------------------------------------------------------------------- |
| 层数2 | 120%超击破伤害，10%初始韧性和韧性恢复量降低。                                                        |
| 层数4 | 180%超击破伤害，20%初始韧性和韧性恢复量降低。击破敌人会充能【冲击波】。                              |
| 层数6 | 300%超击破伤害，30%初始韧性和韧性恢复量降低。【冲击波】触发时，我方小队恢复等同于能量上限30%的能量。 |
| 层数9 | 500%超击破伤害，99%初始韧性和韧性恢复量降低。                                                        |

**备注**

- 【冲击波】：普通/精英/首领敌人被击破时，获得1/3/6点充能，累计获得12点充能后，消耗12点充能发动【冲击波】，击破敌方全体目标并触发随机弱点击破效果，使其受到的伤害提高50%，并对敌方全体造成等同于600%/1500%/3000%基础伤害的真实伤害。
