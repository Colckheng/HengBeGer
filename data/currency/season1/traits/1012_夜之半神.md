# 夜之半神

> English name: Night Demigod

**ID**：1012 · **成员数**：7

---

每个战斗阶段后生成【月光精华】，完胜后获得2倍【月光精华】。获得足够的【月光精华】后可以获取晶矿奖励。【夜之半神】队员的前台强度后台强度前/后台强度提高。

| 层数  | 效果               |
| ----- | ------------------ |
| 层数2 | 2个【月光精华】。  |
| 层数4 | 5个【月光精华】。  |
| 层数7 | 9个【月光精华】。  |
| 层数9 | 30个【月光精华】。 |

**备注**

- 【晶矿】开启后可能获取金币、角色、装备或其它稀有物品！
