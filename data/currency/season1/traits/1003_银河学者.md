# 银河学者

> English name: Cosmic Scholar

**ID**：1003 · **成员数**：5

---

基于【银河学者】们的星级叠加【猫猫糕】，并根据层数获得额外奖励。

| 层数  | 效果                             |
| ----- | -------------------------------- |
| 层数2 | 30%前台强度后台强度前/后台强度。 |
| 层数4 | 获得1.5倍【DNA】。               |
| 层数6 | 获得2倍【DNA】。                 |

**备注**

- 【猫猫糕】：【银河学者】队员的前台强度后台强度提高，并在我方前台回合开始时为其回复等同于其生命增幅20%的生命，每层【猫猫糕】使该倍率提高5%。我方前台伤害减免提高15%，每层【猫猫糕】使该倍率提高3%。
- 每星级【银河学者】提供的【DNA】进度为2/4/8/20。
