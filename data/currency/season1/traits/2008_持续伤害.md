# 持续伤害

> English name: DoT

**ID**：2008 · **成员数**：5

---

【持续伤害】队员的持续伤害增幅持续伤害增幅提高。敌方目标行动时，触发【超激发】，造成持续伤害并触发随机敌方目标的持续伤害效果。

| 层数  | 效果                                                                                    |
| ----- | --------------------------------------------------------------------------------------- |
| 层数2 | 【超激发】触发2次。                                                                     |
| 层数4 | 【超激发】触发3次。基础伤害倍率提高至480%。非首领敌方目标被消灭时，额外触发【超激发】。 |
| 层数6 | 【超激发】触发6次。基础伤害倍率提高至960%。                                             |

**备注**

- 【超激发】：对随机敌方目标造成240%基础伤害的持续伤害，并使其陷入的持续伤害状态立即产生相当于原伤害250%的伤害。
