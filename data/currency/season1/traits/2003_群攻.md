# 群攻

> English name: AoE ATK

**ID**：2003 · **成员数**：7

---

【群攻】队员的幸运一击率提高，幸运一击伤害提高。进入战斗后在敌方场上生成2个可转移伤害的【借力球】。

| 层数  | 效果                                                                                                                                                        |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 层数3 | 将受到伤害的40%转移给其他敌方目标。                                                                                                                         |
| 层数5 | 将受到伤害的60%转移给其他敌方目标。累计受到6次攻击后，发射激光造成8次250%基础伤害的量子属性伤害，单次攻击内最多累计1次。                                    |
| 层数7 | 将受到伤害的100%转移给其他敌方目标，并使首领敌人受到的伤害提高30%。累计受到6次攻击后，发射激光造成8次500%基础伤害的量子属性伤害，单次攻击内最多累计1次。    |
| 层数9 | 将受到伤害的100%转移给其他敌方目标，并使首领敌人受到的伤害提高100%。累计受到6次攻击后，发射激光造成12次1500%基础伤害的量子属性伤害，单次攻击内最多累计1次。 |

**备注**

- 【借力球】：受到攻击后，使攻击者对其他敌方目标造成真实伤害，数值等同于自身本次攻击内所受伤害的一定比例。【借力球】免疫控制类负面状态。
