# 八套 UI Demo · 第三版

入口：[第三版设计总览](http://127.0.0.1:5175/demo.html?edition=3)。总览可切换「主页 / 列表 / 详情」的真实浏览器截图，点击图片进入对应页面。页面底部可保留当前资料切换设计，并快速访问 16 类代表页面。

本轮根据用户对内页重复、图片适配不足的反馈，分别实现八套首页、板块页、列表与详情结构。不使用 frontend-design。搜索、数据解析、等级数值和正文渲染共享，以保持资料口径一致。

## 三大入口与封面

后续新增配图使用[用户指定的五个来源入口](./27-ui-image-sources-2026-10-11.md)，已单独保存完整链接和使用约定。

每套首页均包含三个平级入口。ZZZ、HSR 进入各自分类总览；货币战争进入赛季总览，内部切换 S1 / S2。

## 图片与响应式验收

已逐套查看桌面主页、列表、详情截图，并检查手机代表页面。布局在窄屏下折叠为阅读顺序：目录在前、正文在后；宽表在自身容器内滚动。保留原图色彩，不对三个封面统一套灰度或遮罩。遵循系统减少动画偏好。

Chromium 本机检查结果：

- 8 套 × 16 类 × 1440 / 390 宽度：256 / 256 个视图通过。
- 87 / 87 条样本详情：名称、正文动态标签、页面横向溢出检查通过。
- 8 套 × 3 个板块 × 360 / 768 / 1440 宽度：72 / 72 个板块视图通过。
- 8 套分别验证搜索空结果、清除条件、筛选、技能 Lv.1 → Lv.2 数值变化、S1 → S2 及对应策略链接；额外验证文件选择预览、唱片展开和书籍翻章。
- 总览的三种预览各有 8 张可加载截图，入口可点击。
- 浏览器检查未记录脚本错误或本地资源请求失败。
- 前端测试 18 个文件、56 项通过；定向 ESLint、生产构建通过。构建仍提示空 vendor chunk，不影响完成。

结果汇总与逐页明细：`reports/ui-demo-v3-20261011.json`。这些检查证明已测试的功能与布局成立；审美选择仍由实际体验评估。尚未做真实用户研究、完整无障碍审计、Firefox / Safari 验收。

## 启动与实现位置

```powershell
npm run demo
```

从清单生成样本包后启动 5175 端口。构建使用 `npm run build`，产物为 `dist/demo.html`。当前 Demo 使用本地样本，不依赖数据库。

- `src/demo/DesignHome.jsx`：八套首页。
- `src/demo/WorldLayouts.jsx`：八套板块 / 赛季页。
- `src/demo/CollectionLayouts.jsx`：八套目录结构。
- `src/demo/DetailLayouts.jsx`：八套详情结构。
- `src/demo/Visuals.jsx`、`worlds.js`：图片适配和封面焦点。
- `src/demo/DesignGallery.jsx`：主页、列表、详情对比入口。
- `src/demo/demo-v3.css`：当前样式入口；旧版样式不再导入。
- `src/demo/Reader.jsx`、`model.js`：沿用的数值、正文及筛选逻辑。

本轮没有接入新数据库，也没有替换旧 Wiki 或后台。数据树哈希仍为 `be42e72d6b2abb487e0d6e342e2bfaa788b7cad24c3dae9a13e3006c9eb8d29c`。
