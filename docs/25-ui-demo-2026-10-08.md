## 打开与启动

当前本地入口：[第二版 · 设计总览](http://127.0.0.1:5175/demo.html)。总览直接展示实际首页截图。底部浮动工具条可以保留当前条目切换风格，也可以直接选择 16 类代表页面。

在项目根目录运行：

```powershell
npm run demo
```

该命令根据样本清单生成 `public/demo-data/`，然后启动 5175 端口的本地预览。数据库不是启动条件。重新构建使用 `npm run build`，其 prebuild 会自动生成样本包，产物入口为 `dist/demo.html`。

## 首页与信息结构

每套产品首页均为三个平级入口：**ZZZ / HSR / 货币战争**。

- ZZZ：进入独立分类页，包含代理人、音擎、驱动盘、邦布、敌人、调频、机制。
- HSR：进入独立分类页，包含角色、光锥、遗器、敌人、跃迁、机制。
- 货币战争：进入赛季总览，在内部切换 S1 / S2，包含角色、羁绊、物品、投资策略、投资环境。

设计总览仅用于比较方案，不是产品首页。三大入口在八种风格下保持相同层级。

## 页面与交互

16 类快捷页面：全站首页、分类图鉴、角色详情、武器详情、套装详情、邦布详情、敌人详情、活动时间列表、活动详情、机制文章、赛季总览、赛季角色、羁绊详情、物品详情、投资策略、投资环境。ZZZ / HSR 分类总览与所有 23 个数据分组也可通过导航进入。

实现了名称 / 编号 / 别名搜索、多个条件组合筛选、分页、详情返回保留筛选、同一条目切换设计、技能与真实等级切换、精炼 / 叠影档位、赛季切换、样本之间的关联链接、数学公式和宽表局部滚动。支持加载重试、空结果、缺图与未知条目状态。

样本范围为 87 条，列表同时注明全量目录条数，避免把样本数量误当成完整数据库。62 个样本具有有效目录图片；第二版另补充 9 张官方立绘，用于首页及对应角色。来源清单位于 `public/demo-art/sources.json`。缺图采用明确占位；低分辨率敌人图限制放大；白色羁绊图标使用深色底板。正文为桌面 15px / 手机 14px，表格在自身区域内滚动。

## 数据边界

- 读取 `docs/23-ui-samples-2026-10-08.json`，逐条校验文件哈希；不修改 `data/`。
- 生成目录 `public/demo-data/` 已忽略，不提交重复数据与素材；条目正文按需加载。
- HSR 敌人 Lv.80 摘要与历史正文等级分别展示，避免混用数值。
- 货币战争按赛季和 ID 区分同名记录；有冲突的星级与治疗护盾字段不作为可靠摘要展示。
- 活动时间保留文字日期、长期与缺失状态，明确为来源快照。
- 动态引用尽量解析为名称；只有已选样本生成站内详情链接，未核验说明保留。

Demo 暂未接新数据库，也不替换旧 Wiki 或后台。还没有经过真实用户研究、完整无障碍审计或跨浏览器验收。
