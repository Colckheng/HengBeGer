# Admin Image Validation Design

日期：2026-04-06

## 背景

当前 ZZZ 与 HSR 管理页在选择图片后会直接读取文件并转成 base64，没有在前端做类型或大小校验。这会带来两类问题：

- 选错文件类型时，只有提交后才暴露问题
- 图片过大时，会把无效数据直接传进前端状态和后端请求

## 目标

- 在前端选择图片时立即校验
- 统一 ZZZ 与 HSR 管理页的规则和提示文案
- 校验失败时不写入表单状态、不生成预览、不发请求

## 规则

- 仅允许 `image/*`
- 文件大小不超过 `2MB`

## 方案选择

采用共享工具方案：

- 抽一个前端图片校验工具
- 两个管理页共用同一套规则
- 两边通过现有 `statusMessage` 展示错误

## 交互设计

- 用户未选择文件：清空预览，不报错
- 文件类型不合法：显示错误，清空当前文件输入状态
- 文件超出 2MB：显示错误，清空当前文件输入状态
- 文件合法：读取为 base64，更新预览

## 非目标

- 本次不改后端图片长度限制
- 本次不做图片压缩或自动缩放
- 本次不增加拖拽上传
